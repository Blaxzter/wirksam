## „Marken einlösen“ öffnen

Öffne WirkSam auf dem Handy und melde dich an. Tippe unten auf „Mehr“, dann auf „Marken“. Unter „Code zeigen“ steht der Knopf „Marken einlösen“. Du findest ihn auch auf der Seite deiner Aufgabe unter „Aufgaben“, in der Karte „Marken“.

Der Knopf erscheint 30 Minuten vor deiner Schicht und bleibt bis 30 Minuten nach ihrem Ende. Hat die Schicht keine Uhrzeit, gilt der ganze Tag. Verantwortliche und Organisator:innen können jederzeit einlösen, bis die Veranstaltung vorbei ist.

Fehlt der Knopf, prüfe die Uhrzeit und ob die richtige Veranstaltung ausgewählt ist („Mehr“, dann „Veranstaltung wechseln“).

## Den Ort prüfen

Oben neben „Wo“ steht dein Stand. Darfst du gerade an mehreren Orten einlösen, wählst du hier den richtigen. Die Einlösung wird für diesen Ort gezählt.

![Marken einlösen auf dem Handy, oben der Ort, darunter der Code und der Knopf für die Personenliste](phone:vouchers-redeem)

## Code scannen oder eintippen

Die Person öffnet „Meine Marken“ und tippt auf „Code zeigen“. Halte den QR-Code vor die Kamera. Beim ersten Mal fragt der Browser nach der Kamera, erlaube das. Die Kamera läuft danach von Person zu Person weiter.

Geht das Scannen nicht, tippe auf „Code stattdessen eintippen“, gib die sechs Zeichen ein und tippe auf „Weiter“. Bindestrich und Kleinschreibung sind egal. Die Zeichen 0, O, 1, I und L kommen in Codes nicht vor.

![Der Code zum Vorzeigen, als QR-Code und zum Abtippen](phone:vouchers-code)

## Anzahl wählen und einlösen

Es öffnet sich ein Fenster mit dem Namen und den verfügbaren Marken. Prüfe kurz den Namen. Unter „Wie viele?“ stellst du mit Plus und Minus die Anzahl ein, los geht es bei 1. Mehr, als die Person hat, geht nicht. Tippe dann auf den Knopf, zum Beispiel „2 Marken einlösen“. Ein großes Häkchen zeigt, dass es geklappt hat und wie viele noch übrig sind.

Tippe auf „Nächste Person“, und die Kamera ist für die nächste Person bereit. „Fertig“ schließt nur das Fenster. Weiter unten auf der Seite siehst du die letzten Einlösungen und die Summe von heute.

Der Code bleibt nach dem Scannen mindestens eine Minute gültig, du musst dich also nicht beeilen. Rückgängig machen lässt sich eine Einlösung am Stand nicht. Stimmt die Anzahl nicht, sag den Organisator:innen Bescheid, sie können das korrigieren.

## Ohne Code: Person auswählen

Hat die Person einen leeren Akku, kein Netz oder kein Smartphone, tippe auf „Person auswählen“. Das ist nur für diesen Fall gedacht. In der Liste suchst du nach Name oder E-Mail. Neben jedem Namen steht, wie viele Marken die Person hat. Wer keine hat, ist ausgegraut und lässt sich nicht wählen. Danach geht es weiter wie beim Code.

Steht dort stattdessen „Kein Handy? Frag …“, hat diese Veranstaltung das Einlösen ohne Code den Verantwortlichen und Organisator:innen vorbehalten. Schick die Person zu den Genannten.

![Die Personenliste beim Einlösen ohne Code, mit der Zahl der Marken neben jedem Namen](phone:vouchers-picker)

## Auf Meldungen reagieren

- **„Schon eingelöst: 2 Marken bei Küche, 14:03“:** Dieser Code wurde schon benutzt. Die Marken sind damals abgezogen worden, jetzt wird nichts mehr abgezogen. Für weitere Marken zeigt die Person über „Neuen Code zeigen“ einen neuen.
- **„Diese Aufgabe ist archiviert und nimmt keine Marken mehr an“:** Die Organisator:innen haben die Stelle archiviert, während deine Seite offen war. WirkSam nimmt sie aus der Liste, wähle also eine andere.
- **„Dieser Code ist abgelaufen“:** Ein Code gilt zwei Minuten. Bitte um den aktuellen, auf dem Handy der Person erscheint er von selbst.
- **„Dieser Code ist ungültig“ oder „Das ist kein Marken-Code“:** Vertippt oder ein anderer QR-Code. Lass dir den Code noch einmal zeigen.
- **„Dieser Code gehört zu einer anderen Veranstaltung“:** Die Person wechselt in der App zu dieser Veranstaltung und zeigt einen neuen Code.
- **„… hat keine Marken mehr zum Einlösen“:** Es wurde nichts abgezogen. Neue Marken gibt es erst, wenn die Person wieder eine Schicht gearbeitet hat, die Marken bringt.
- **„Marken annehmen kannst du hier nur während deiner Schicht hier …“:** Deine Zeit ist um. Gib an die nächste Schicht ab oder frag die Verantwortlichen.
- **Keine Antwort beim Einlösen:** Tippe im selben Fenster noch einmal auf den Knopf. Auch bei schlechtem Netz zählt es nur einmal.

Geht die Kamera nicht, öffnet sich das Feld zum Eintippen von selbst, und du kannst sofort weitermachen. Steht dort „Der Zugriff auf die Kamera wurde verweigert“, erlaube die Kamera in den Browser-Einstellungen und lade die Seite neu. Bei allen anderen Kamera-Meldungen hilft der Code zum Eintippen oder ein anderes Handy.
