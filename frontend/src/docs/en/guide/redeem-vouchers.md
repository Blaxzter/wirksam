## Open "Redeem vouchers"

Open WirkSam on your phone and sign in. Tap "More" at the bottom, then "Vouchers". The "Redeem vouchers" button is below "Show my code". You'll also find it on your task's page under "Tasks", in the Vouchers card.

The button appears 30 minutes before your shift and stays until 30 minutes after it ends. If the shift has no times, it's there all day. People in charge and organisers can redeem at any time until the event is over.

If the button is missing, check the time and whether the right event is selected ("More", then "Change event").

## Check the place

Next to "Where" [[place]] at the top is your stand. If you can redeem at several places right now, choose the right one here. The redemption is counted for that place.

![Redeeming vouchers, with the place at the top, then the code and the button for the list of people](shot:vouchers-redeem)

## Scan or type the code

The volunteer opens "My vouchers" and taps "Show my code". Hold the QR code [[qr]] in front of the camera. The first time, your browser asks about the camera, so allow it. The camera then keeps running from one person to the next.

If scanning doesn't work, tap "Type the code instead", enter the six characters [[code]] and tap "Continue". Dashes and small letters don't matter. Codes never contain 0, O, 1, I or L.

![The code to show, as a QR code and to type in](shot:vouchers-code)

## Choose the amount and redeem

A window opens with the name and the vouchers available. Check the name. Under "How many?", set the amount with plus and minus, starting from 1. You can't go above what the person has. Then tap the button, such as "Redeem 2 vouchers". A big tick shows it worked and how many are left.

Tap "Next person", and the camera is ready for the next one. "Done" only closes the window. Further down the page you see the latest redemptions and today's total.

The code stays valid for at least a minute after scanning, so there's no need to rush. You can't undo a redemption at the stand. If the amount is wrong, tell the organisers, who can correct it.

## No code: pick the person

If the person's battery is flat, or they have no signal or no smartphone, tap "Pick a person". This is only meant for that case. Search the list by name or email [[search]]. Each name shows how many vouchers the person has [[count]]. People with none are greyed out and can't be chosen. After that it works the same as with a code.

If it says "No phone? Ask …" instead, your event keeps redeeming without a code to people in charge and organisers. Send the person to whoever is named.

![The list of people when redeeming without a code, with the number of vouchers next to each name](shot:vouchers-picker)

## Respond to messages

- **"Already redeemed: 2 vouchers at Kitchen, 14:03":** This code has been used. Those vouchers were taken then, and nothing more is taken now. For more vouchers, the person shows a new code with "Show a new code".
- **"This task is archived, so it no longer takes vouchers":** An organiser has archived this place while your page was open. WirkSam takes it off the list, so choose another one.
- **"This code has expired":** A code lasts two minutes. Ask for the current one, which appears on the person's phone by itself.
- **"This code isn't valid" or "That is not a voucher code":** A typo, or a different QR code. Ask to see the code again.
- **"This code is for a different event":** The person switches to this event in the app and shows a new code.
- **"… has no vouchers left to redeem":** Nothing was taken. New vouchers only come once the person has worked another shift that brings them.
- **"You can only take vouchers here while you are on shift here …":** Your time is up. Hand over to the next shift or ask the people in charge.
- **No answer when redeeming:** Tap the button again in the same window. Even on a bad connection it only counts once.

If the camera doesn't work, the field for typing opens by itself and you can carry on straight away. If it says "Camera access was refused", allow the camera in your browser settings and reload the page. For any other camera message, type the code or use another phone.
